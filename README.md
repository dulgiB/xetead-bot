# xetead-bot

TRPG 캠페인의 전투를 자동 정산하는 Mastodon 봇.

---

## 실행

### 환경 변수

`.env` 파일을 생성하거나 환경 변수를 직접 설정한다.

| 변수                               | 설명                                      |
|----------------------------------|-----------------------------------------|
| `ADMIN_MASTODON_ID`              | Admin 마스토돈 계정 (`user` 또는 `user@domain`) |
| `MASTODON_ACCESS_TOKEN`          | 봇 계정 액세스 토큰                             |
| `MASTODON_API_BASE_URL`          | 마스토돈 인스턴스 URL                           |
| `GOOGLE_SPREADSHEET_CREDENTIALS` | Google 서비스 계정 JSON (문자열)                |
| `DB_SPREADSHEET_KEY`             | 스프레드시트 ID (내부용 자동화 DB)                  |
| `FIELD_SPREADSHEET_KEY`          | 스프레드시트 ID (관중 공개용 실시간 전투 UI "필드" 시트)     |

### 봇 시작

```bash
pip install -r requirements.txt
PYTHONPATH=app python app/bot/main.py
```

## 스프레드시트 설정

### 캐릭터 시트

| 컬럼                                                                               | 설명                                |
|----------------------------------------------------------------------------------|-----------------------------------|
| `name`                                                                           | 캐릭터 이름                            |
| `mastodon_id`                                                                    | 마스토돈 계정 (`user` 또는 `user@domain`) |
| `curr_hp`, `max_hp`                                                              | 현재/최대 체력                          |
| `atk`                                                                            | 공격력                               |
| `attack_range`                                                                   | 사거리                               |
| `m_res`                                                                          | 마법 저항 (`낮음` / `보통` / `높음`)        |
| `is_magic`                                                                       | 마법 공격자 여부                         |
| `max_cost`                                                                       | 최대 코스트                            |
| `passive_buff_id`                                                                | 패시브 버프 ID                         |
| `skill_1_id` ~ `skill_N_id`                                                      | 스킬 ID 목록                          |
| `stat_physical`, `stat_knowledge`, `stat_human`, `stat_magic`, `stat_technology` | 비전투 스탯 (0–5) — 육체·지식·인간·마법·기술     |
| `gold`                                                                           | 보유 골드                             |
| `daily_quest_date`                                                               | 마지막 일일 의뢰 날짜 (`YYYY-MM-DD`)       |

### 에너미 시트

전투 전용 캐릭터(몬스터 등) 데이터. 컬럼 구성은 캐릭터 시트와 같되 비전투 스탯·`gold`·`daily_quest_date` 컬럼은 없으며, 스킬은 `스킬_캐릭터`가 아닌 `스킬_에너미` 시트에 등록한다.

| 컬럼                           | 설명                                                    |
|------------------------------|-------------------------------------------------------|
| `name`                       | 에너미 이름                                                |
| `mastodon_id`                | 마스토돈 계정. 비워두면 계정 없는 에너미(`[배치/...]`로만 조작, 프록시 커맨드 필요) |
| `curr_hp`, `max_hp`          | 현재/최대 체력                                              |
| `atk`                        | 공격력                                                   |
| `attack_range`               | 사거리                                                   |
| `m_res`                      | 마법 저항 (`낮음` / `보통` / `높음`)                            |
| `is_magic`                   | 마법 공격자 여부                                             |
| `max_cost`                   | 최대 코스트                                                |
| `passive_skill_id`           | 패시브 스킬 ID                                             |
| `skill_1_id` ~ `skill_N_id`  | 스킬 ID 목록 (`스킬_에너미` 시트의 `id` 참조)                       |

- `에너미` 시트 자체가 없어도(레거시 데이터) 봇은 경고만 남기고 에너미 없이 정상 동작한다.
- `mastodon_id`가 있는 에너미는 캐릭터와 동일하게 본인 계정으로 전투 커맨드를 입력할 수 있다.
- 판정/의뢰/아이템 사용 등 비전투 커맨드의 대상이 될 수 없다.

### 아이템 시트

독립적인 코스트와 사거리를 가진 소비형 슬롯. 효과·대상 규칙은 스킬 시스템을 그대로 재사용하며, 효과는 **1개**(`effect_0`)만 가진다.

| 컬럼                                                                | 설명                                                                                    |
|-------------------------------------------------------------------|---------------------------------------------------------------------------------------|
| `id`                                                              | 아이템 이름 (= ID, 고유)                                                                     |
| `target_rule`                                                     | 대상 규칙 클래스명 (`SkillTargetRuleSelf` / `SkillTargetRuleNamed` / `SkillTargetRuleColumn`) |
| `cost`                                                            | 코스트                                                                                   |
| `range`                                                           | 사거리 (아이템 고유 — 캐릭터 사거리와 무관)                                                            |
| `effect_0`                                                        | 효과 클래스명 (스킬 효과 재사용: `SkillEffectDamage`, `SkillEffectHeal`, `SkillEffectAddBuff` 등)   |
| `value_source_0`, `value_0`, `value_type_0`                       | 효과 수치 정의 (대미지/회복 계산 참조)                                                               |
| `buff_name_0`                                                     | 버프 부여 효과일 때 버프 ID                                                                     |
| `buff_add_timing_0`, `target_override_0`, `effect_apply_timing_0` | 선택 옵션 (스킬 `effect_0` 컬럼과 동일 구조)                                                       |

- `target_count` 컬럼은 없다. 대상 수 상한 검증 없이 `target_rule`에 위임한다.
- 커맨드 형식은 [아이템](#아이템) 참조.

### 인벤토리 시트

캐릭터별 아이템 보유 현황. `(character_name, item_id)`가 key인 dict처럼 취급한다.

| 컬럼               | 설명     |
|------------------|--------|
| `character_name` | 캐릭터 이름 |
| `item_id`        | 아이템 이름 |
| `count`          | 보유 개수  |

- 아이템 사용이 확정되면 `count`가 **즉시 1 차감되어 시트에 기록**된다.
- 보유 개수가 0이거나 인벤토리에 없는 아이템은 사용할 수 없다.
- **대련·상시전투에서는 아이템을 사용할 수 없다.**

## 전투 시스템

### 전장 구조

전장은 **7열 × 진영(아군/적군)** 구조다. 각 열에는 최대 3명이 위치할 수 있다.

```
적군  [1열] [2열] [3열] [4열] [5열] [6열] [7열]
아군  [1열] [2열] [3열] [4열] [5열] [6열] [7열]
```

사거리는 열 번호 차이로 계산한다.

```
사거리 = |내 열 - 대상 열|

예) 내가 2열, 사거리 2 → 1열~4열의 적 공격 가능
```

### 캐릭터 스탯

| 스탯    | 설명                                           |
|-------|----------------------------------------------|
| 공격력   | 기본 공격 및 공격 계수 스킬의 주사위 상한                     |
| 체력    | 최대/현재 HP                                     |
| 사거리   | 공격 가능한 열 거리 (1 = 인접, 3 = 원거리)                |
| 공격 속성 | 물리 / 마법                                      |
| 마법 저항 | 낮음(+10%) / 보통(±0) / 높음(−10%). 마법 공격을 받을 때 적용 |
| 코스트   | 턴당 행동 자원                                     |

### 라운드 페이즈

한 라운드는 4단계로 진행된다.

```
① 적군 행동 선언
   봇이 "[라운드 N] 적군 행동 선언" 게시물을 올린다.
   이 시점에 적군의 이동이 처리된다.
   적군 플레이어가 있다면 이 게시물에 답글로 커맨드를 입력한다.

② 아군 행동  ← 플레이어 행동 타이밍
   봇이 "[라운드 N] 아군 행동" 게시물을 올린다.
   이 게시물에 답글로 커맨드를 입력하면 된다.
   모두 입력을 마치면 관리자에게 알린다.

③ 적군 행동 정산
   ①에서 선언된 적군의 공격·스킬 효과가 실제로 처리된다.
   ②에서 건 버프(도발 등)가 이 시점에 반영된다.
   HP 변동 결과가 출력된다.

④ 라운드 종료
   버프/디버프 지속 턴이 차감된다.
   [전투 속행] 또는 [전투 종료]로 전투를 이어간다.
```

## 커맨드 입력

### 커맨드 형식

커맨드는 `[행동1 - 행동2 - ...]` 형태로 작성하며, `-`로 복수 행동을 연결한다.

```
예) [이동/3 - 공격/오크A]
    [이동/3 - 스킬/강타/오크A]
    [공격/골렘 - 공격/오크A]
    [스킬/도발 - 스킬/방어태세]
```

**Discord 봇 예시**: `/행동 이름:테스트 커맨드:"[이동/2 - 공격/에너미]"`

### 행동 종류

#### 이동

```
이동/[열 번호]
예) 이동/3   → 3열로 이동
```

- 목표 열에 빈 슬롯이 있어야 한다 (열당 최대 3명).
- 코스트 소모 없음.

#### 기본 공격

```
공격/[대상 이름]
예) 공격/오크A
```

- 대상이 사거리 내에 있어야 한다.
- 코스트 1 소모.

#### 스킬

```
스킬/[스킬명]                   # 자신 고정 (대상 생략)
스킬/[스킬명]/[대상1]/[대상2]   # 이름 지정
스킬/[스킬명]/[열 번호]         # 열 지정 (광역)
```

```
예) 스킬/강타/오크A          ← 이름 지정
    스킬/광역폭발/2/3         ← 열 번호 지정
    스킬/자가회복             ← 자신 고정 (대상 생략)
```

대상 지정 방식은 스킬마다 다르다.

| 방식    | 입력 형식    | 사거리 제한 |
|-------|----------|--------|
| 이름 지정 | 캐릭터 이름   | 있음     |
| 열 지정  | 1~7 열 번호 | 없음     |
| 자신 고정 | 생략       | 없음     |

#### 아이템

```
아이템/[아이템명]           # 자신에게 사용
아이템/[아이템명]/[대상]    # 대상 지정
```

```
예) 아이템/포션             ← 자신에게 사용
    아이템/해독제/아군B
```

### 코스트 시스템

- 각 캐릭터는 라운드마다 정해진 코스트를 보유한다.
- 행동별 기본 소모량: 이동 **0** / 공격 **1** / 스킬·아이템 **스킬마다 다름**
- 커맨드 전체의 코스트 합산이 보유 코스트를 초과하면 **커맨드 전체가 취소**된다 (일부만 처리되지 않음).
- 라운드 시작 시 코스트가 전액 회복된다.

### 검증 항목

커맨드 실행 전 아래 항목을 순서대로 검증하며, 하나라도 실패하면 전체 커맨드가 취소된다.

1. 커맨드 사용자가 전장에 존재하는지
2. 지정한 스킬이 캐릭터에 등록되어 있는지
3. 스킬 대상 수가 `target_count`를 초과하지 않는지
4. 커맨드 전체 코스트가 잔여 코스트 이내인지
5. 공격/힐 대상이 전장에 존재하는지, 사거리 내인지
6. 이동 목적지에 자리가 남아있는지

### 캐릭터 이름 규칙

커맨드에 캐릭터 이름을 입력할 때는 다음 문자만 허용된다.

- 한글 (완성형 음절, 자모)
- 영문 (A–Z, a–z)
- 숫자 (0–9)
- 공백

```
가능: 오크A, Monster1, 아군 기사
불가: 오크-A, 몬스터@1
```

## 대미지 · 회복 계산

```
최종 수치 = floor(기본값 × (1 + Σ배율 보정)) + Σ정수 보정
```

### 대미지 기본값 종류

| 종류         | 설명                          |
|------------|-----------------------------|
| 고정값        | 정해진 수치                      |
| 공격 굴림      | `nd6(마일스톤N, 공격력)` 주사위 굴림 결과 |
| 기본 공격력     | 캐릭터의 공격력 스탯                 |
| 현재 체력 (자신) | 시전 시점의 자신 HP                |
| 현재 체력 (대상) | 시전 시점의 대상 HP                |
| 이전 효과의 대미지 | 같은 스킬의 앞선 효과가 입힌 대미지        |

### 마법 공격

마법 공격은 대상의 마법 저항에 영향을 받는다. 물리 공격은 영향 없음.

| 마법 저항       | 효과       |
|-------------|----------|
| 낮음 (WEAK)   | 대미지 +10% |
| 보통 (NORMAL) | 변화 없음    |
| 높음 (STRONG) | 대미지 -10% |

### 회복

회복량도 대미지와 같은 공식으로 계산된다. 최대 체력을 초과해 회복할 수 없다.

## 버프 · 디버프 시스템

### 지속 시간

| 종류    | 해제 조건                          |
|-------|--------------------------------|
| 턴 지속  | 라운드 종료 시마다 1 차감. 0이 되면 해제.     |
| 횟수 지속 | 공격하거나 피격당할 때마다 1 차감. 0이 되면 해제. |
| 영구    | 별도 해제 수단이 없으면 계속 유지.           |

### 발동 타이밍

| 타이밍              | 발동 시점    |
|------------------|----------|
| `ON_ROUND_START` | 라운드 시작 시 |
| `ON_ACTION`      | 공격/피격 시  |
| `ON_ROUND_END`   | 라운드 종료 시 |

### 구현된 버프 목록

| 버프 클래스               | 효과                      |
|----------------------|-------------------------|
| `BuffAtk`            | 공격력 수치 증가               |
| `BuffReceivedDamage` | 받는 대미지 배율 변경            |
| `BuffGivenDamage`    | 주는 대미지 배율 변경            |
| `BuffDamageOverTime` | 매 라운드 지속 대미지            |
| `BuffHealOverTime`   | 매 라운드 지속 회복             |
| `BuffNoDamage`       | 대미지 무효                  |
| `BuffNoHeal`         | 회복 무효                   |
| `BuffTaunt`          | 도발 — 홀더의 모든 공격이 도발자를 향함 |

### 도발 상세

- 도발이 걸린 캐릭터는 적군이 공격 대상을 정할 때 강제로 그 캐릭터로 대상이 교체된다.
- **아군 행동(②)** 페이즈에서 도발을 걸면, 같은 라운드 **적군 행동 정산(③)** 때 바로 효과가 적용된다.
- 도발 대상이 사거리 밖에 있으면 공격이 실행되지 않는다.

## 봇 커맨드

### 기본 규칙

- 봇은 **멘션(@시스템계정)** 에만 반응한다.
- Admin 계정(`ADMIN_MASTODON_ID`)의 멘션은 전투 관리 커맨드로 처리된다.
- 일반 캐릭터는 **답글의 맥락**(어느 게시물에 답글을 달았는지)에 따라 전투 커맨드 또는 비전투 커맨드로 처리된다.
- 최대 게시물 길이는 500자이며, 초과 시 잘린다.
- 봇 답글의 가시성: 원본 멘션의 가시성을 그대로 유지.

### 공개 필드 시트

관중에게 공개하는 실시간 전투 UI. 내부 자동화 DB(`DB_SPREADSHEET_KEY`)와는
별개인 `FIELD_SPREADSHEET_KEY` 스프레드시트의 "필드" 시트에 라운드/페이즈/
캐릭터 상태/버프/적 선언 내용을 갱신하고, 그 시트를 그대로 이미지로 캡처해
Mastodon 게시물에 첨부한다.

- 이미지가 첨부되는 시점: 라운드 시작(`[전투개시]`/`[전투속행]`), 라운드
  종료(버프 턴 차감/제거가 끝난 직후), 그리고 본 전투 캐릭터 커맨드/프록시
  커맨드의 답글.
- 대련·상시전투에는 적용되지 않는다.
- 시트 캡처나 업로드가 실패해도 전투 진행 자체는 막히지 않고 텍스트만
  게시된다.

### Admin 명령어

Admin 계정의 멘션은 답글 여부에 무관하게 항상 Admin 커맨드로 처리된다.

#### `[전투 준비]`

새 전투 세션을 생성한다.

- 실행 시점에 스프레드시트 캐릭터 시트를 새로 읽어 최신 데이터를 반영한다.
- 봇 답글 자체가 **참전 신청 스레드**가 된다.
- 이 게시물에 답글을 달면 해당 캐릭터가 참전 신청자 목록에 추가된다.

```
[전투 준비]
```

#### `[배치/캐릭터이름/팩션 열]`

전투 시작 전 특정 캐릭터를 수동으로 지정 열에 배치한다.

```
[배치/늑대/적군 3열]
[배치/용병A/아군 2]
```

- 팩션: `아군` 또는 `적군`
- 열: `1`~`7` 또는 `1열`~`7열`

#### `[전투 개시]`

참전 신청자 및 수동 배치 목록을 확정하고 전투를 시작한다.

- 아군 참전 신청자는 열(1~7)에 자동 배치(랜덤 분산)된다.
- 첫 페이즈(적군 행동 선언)의 게시물이 퍼블릭으로 게시되며, 공개 필드 시트
  이미지(아래 [공개 필드 시트](#공개-필드-시트) 참고)가 함께 첨부된다.
- `[전투개시「전투 이름」]`처럼 「」로 감싸 전투 이름을 지정하면 공개 필드
  시트의 타이틀에 반영된다. 지정하지 않으면 기존 표기가 유지된다.

```
[전투개시]
[전투개시「1라운드 습격전」]
```

#### `[진행]`

현재 페이즈에서 다음 페이즈로 진행한다.

| 페이즈       | 설명                | 커맨드 수신 |
|-----------|-------------------|--------|
| 적군 행동 선언  | 적군 캐릭터가 커맨드를 입력한다 | ✅      |
| 아군 행동     | 아군 캐릭터가 커맨드를 입력한다 | ✅      |
| 적군 공격 정산  | 적군의 선언된 행동이 처리된다  | ❌      |
| 라운드 종료 대기 | 버프 갱신 후 대기        | ❌      |

- "라운드 종료 대기"로 진행하는 시점(버프 턴 차감/제거까지 끝난 직후)의
  공개 게시물에는 공개 필드 시트 이미지가 함께 첨부된다.

#### `[전투 속행]`

라운드 종료 대기 상태에서 다음 라운드(적군 행동 선언)로 진행한다. 이때도
공개 게시물에 공개 필드 시트 이미지가 첨부된다.

#### `[전투 종료]`

세션을 종료하고 모든 전투 상태를 초기화한다.

#### `[대련]`

멘션된 캐릭터들 간의 1:1 대련을 준비한다.

- 멘션된 계정들이 참여 대상이 된다.
- 봇이 준비 게시물을 올리면 `[1팀/N열]` 또는 `[2팀/N열]` 형식으로 포지션을 선언한다.
- 모든 참여자가 포지션을 선언하면 대련이 자동으로 시작된다.
- 라운드 상한: `max(3, 참여자 수 + 1)`

```
[대련] @캐릭터A @캐릭터B
```

#### `[상시전투]`

상시조사 구간 중 발생하는 전투를 준비한다.

- 멘션된 아군 계정들이 참여 대상이 된다.
- `[배치/이름/진영 열]`을 같은 메시지에 포함해 적군을 즉시 배치할 수 있다.
- 봇이 준비 게시물을 올리면 `[아군/N열]` 형식으로 포지션을 선언한다.

```
[상시전투] @캐릭터A [배치/몬스터/적군 4열]
```

#### `캐릭터이름 [커맨드]` (프록시)

특정 캐릭터 대신 커맨드를 실행한다. 마스토돈 계정이 없는 적군 캐릭터 조작에 사용한다.

```
늑대 [이동/3 - 공격/전사]
```

### 캐릭터 명령어 (전투 중)

**적용 조건:** 전투가 진행 중이고, 해당 캐릭터의 페이즈인 경우에만 처리된다.

- 아군: `아군 행동` 페이즈의 게시물에 답글
- 적군: `적군 행동 선언` 페이즈의 게시물에 답글

커맨드 형식은 [커맨드 입력](#커맨드-입력) 섹션과 동일하다.

### 비전투 명령어

`char_dict`에 등록된 모든 캐릭터가 사용할 수 있다. 전투 맥락과 무관하게 언제든 사용 가능하다.

#### `[판정/스탯]`

1d6을 굴려 해당 스탯값을 더한 결과를 출력한다.

```
@system [판정/마법]
@system [판정/기술]
```

사용 가능한 스탯: `육체` · `지식` · `인간` · `마법` · `기술`

출력 예시:

```
[마법] 4+3 → 「7」
```

#### `[의뢰]` — 일일 의뢰

현재 위치에서 의뢰를 받는다. 1일 1회 제한.

```
캐릭터: @system [의뢰]
  └→ 봇: 의뢰 내용 설명 (스프레드시트 '일일 의뢰' 시트에서 랜덤 선택)

캐릭터: @봇답글 [판정/스탯]
  └→ 봇: [스탯] 주사위+값 → 「합계」
        (성공 유형별 메시지)
        의뢰를 완수했다. 사례로 1G를 획득했다.
```

판정 합계에 따른 성공 유형:

| 합계  | 성공 유형    |
|-----|----------|
| ≥ 7 | 대성공      |
| 5–6 | 성공       |
| ≤ 4 | 아슬아슬한 성공 |

- 결과와 관계없이 항상 **1G 획득**된다.
- 골드와 날짜가 스프레드시트 캐릭터 시트에 자동 업데이트된다.

#### `[상시조사]`

`현위치` 시트에서 `investigation_active = TRUE`일 때만 사용 가능하다.

```
캐릭터: @system [상시조사]
  └→ 봇: 장소 선택 메뉴 (3개 수주처 + 자율 탐사)

캐릭터: @봇답글 [장소명]
  ├→ (의뢰 존재 & 미수주) 봇: 의뢰 개요 + "[수락] 입력" 안내
  ├→ (이미 다른 캐릭터가 수주) 봇: 해당 장소 묘사만 출력
  └→ (자율 탐사 선택) 봇: "자유롭게 돌아다닐 수 있습니다."

캐릭터: @봇답글 [수락]
  └→ 봇: "수락 확인. 「의뢰명」 의뢰를 수주했습니다."
```

다른 캐릭터가 수주한 의뢰의 개요 게시물에 `[수락]`을 답글로 달면 해당 의뢰에 합류할 수 있다.

- 이번 상시조사 구간에서 1인 1의뢰만 수주 가능하다.

### 디스패치 흐름

봇이 멘션을 받으면 아래 순서로 처리 경로를 결정한다.

```
멘션 수신
│
├─  1. 발신자가 Admin 계정? 또는 봇 자신의 [상시전투] 멘션?
│       └→ Admin 커맨드 처리 (전투 관리)
│
├─  2. 대련/상시전투 준비 게시물에 대한 답글?
│       ├─ 상시전투: [아군/N열] 포지션 선언 처리
│       └─ 대련: [N팀/N열] 포지션 선언 처리 → 모두 선언 시 자동 시작
│
├─  3. 대련/상시전투 진행 중 커맨드 (active 게시물에 대한 답글)?
│       └→ 대련/상시전투 캐릭터 커맨드 처리
│
├─  4. [전투 준비] 게시물에 대한 답글?
│       └→ 참전 신청 목록에 추가
│
├─  5. 현재 페이즈 게시물에 대한 답글? (전투 중)
│       └→ 캐릭터 커맨드 처리 (이동/공격/스킬/아이템)
│
├─  6. 봇의 [의뢰] 안내 게시물에 대한 답글? + [판정/스탯] 포함?
│       └→ 일일 의뢰 판정 처리
│
├─  7. 봇의 [상시조사] 메뉴 게시물에 대한 답글?
│       └→ 장소 선택 처리 → 의뢰 개요 또는 탐사 안내 반환
│
├─  8. 봇의 의뢰 개요 게시물에 대한 답글? + [수락] 포함?
│       └→ 의뢰 수락 처리
│
├─  9. [판정/스탯] 포함?
│       └→ 독립 판정 처리 (롤플레이용)
│
├─ 10. [의뢰] 포함?
│       └→ 일일 의뢰 시작
│
└─ 11. [상시조사] 포함?
        └→ 상시조사 메뉴 제공 (현위치 시트에서 실시간 조회)
```

답글 맥락(어느 게시물에 달렸는지) 판단이 독립 키워드 판단보다 항상 먼저다.
