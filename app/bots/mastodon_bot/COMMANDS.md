## 기본 규칙

- 봇은 **멘션(@시스템계정)** 에만 반응한다.
- Admin 계정(`ADMIN_MASTODON_ID`)의 멘션은 전투 관리 커맨드로 처리된다.
- 일반 캐릭터는 **답글의 맥락**(어느 게시물에 답글을 달았는지)에 따라 전투 커맨드 또는 비전투 커맨드로 처리된다.
- 최대 게시물 길이는 500자이며, 초과 시 잘린다.
- 봇 답글의 가시성: 원본 멘션의 가시성을 그대로 유지.

## 스프레드시트 설정

### 캐릭터 시트

| 컬럼                                                                               | 설명                                       |
|----------------------------------------------------------------------------------|------------------------------------------|
| `name`                                                                           | 캐릭터 이름                                   |
| `mastodon_id`                                                                    | 마스토돈 계정 (로컬: `user`, 리모트: `user@domain`) |
| `curr_hp`, `max_hp`                                                              | 체력                                       |
| `atk`                                                                            | 공격력                                      |
| `attack_range`                                                                   | 사거리                                      |
| `m_res`                                                                          | 마법저항 (`낮음` / `보통` / `높음`)                |
| `is_magic`                                                                       | 마법 공격자 여부                                |
| `max_cost`                                                                       | 최대 코스트                                   |
| `passive_buff_id`                                                                | 패시브 버프 ID                                |
| `skill_1_id` ~ `skill_N_id`                                                      | 스킬 ID 목록                                 |
| `stat_physical`, `stat_knowledge`, `stat_human`, `stat_magic`, `stat_technology` | 비전투 스탯 (0–5) — 각각 육체·지식·인간·마법·기술에 대응     |
| `gold`                                                                           | 보유 골드                                    |
| `daily_quest_date`                                                               | 마지막 일일 의뢰 날짜 (`YYYY-MM-DD`)              |

### 일일 의뢰 시트

| 컬럼            | 설명                          |
|---------------|-----------------------------|
| `id`          | 의뢰 ID (고유)                  |
| `name`        | 의뢰 이름                       |
| `description` | 봇이 그대로 출력할 의뢰 설명            |
| `location`    | 이 의뢰가 제공되는 지역 (빈 값이면 위치 무관) |

### 일반 의뢰 시트

| 컬럼                | 설명                         |
|-------------------|----------------------------|
| `id`              | 의뢰 ID (고유)                 |
| `name`            | 의뢰 이름                      |
| `description`     | 봇이 그대로 출력할 의뢰 설명           |
| `type`            | 계열: `운반` / `탐사` / `전투`     |
| `subtype`         | 종류: `상시` / `일반`            |
| `location`        | 의뢰가 등장하는 지역                |
| `venue_name`      | 의뢰 수주처 이름 (상시조사 메뉴에 표시됨)   |
| `reward`          | 보상 내용 (텍스트, 의뢰 종료 시 수동 정산) |
| `available_until` | 클리어 가능 기간 (텍스트, 그대로 출력)    |

### 일일 의뢰 결과 메시지 시트

| 컬럼             | 설명                                                          |
|----------------|-------------------------------------------------------------|
| `success_type` | 성공 유형: `대성공` (합계 ≥ 7) / `성공` (합계 ≥ 5) / `아슬아슬한 성공` (합계 < 5) |
| `message`      | 해당 성공 유형에서 랜덤으로 선택될 메시지 텍스트                                 |

> 같은 `success_type`의 행이 여러 개 있으면 그 중 하나가 무작위로 선택된다.
> 해당 유형의 행이 없으면 `success_type` 값 자체가 출력된다.

### 현위치 시트 (1행)

| 컬럼                                             | 설명                                                |
|------------------------------------------------|---------------------------------------------------|
| `location`                                     | 현재 파티 위치 (일일 의뢰 필터링 및 상시조사에 사용)                   |
| `investigation_active`                         | 상시조사 활성 여부 (`TRUE` / `FALSE`)                     |
| `venue_1`, `venue_2`, `venue_3`                | 상시조사에 표시할 수주처 이름 (일반 의뢰 시트의 `venue_name`과 일치해야 함) |
| `venue_1_desc`, `venue_2_desc`, `venue_3_desc` | 해당 수주처에서 의뢰가 이미 수주됐을 때 출력할 장소 지문 (빈 값이면 출력 생략)    |

> `investigation_active = TRUE`이고 `venue_1~3` 중 하나 이상 채워져 있으면 상시조사 활성 상태로 간주한다.

## Admin 명령어 (전투)

Admin 계정의 멘션은 답글 여부에 무관하게 항상 Admin 커맨드로 처리된다.

### `[전투 준비]`

새 전투 세션을 생성한다.

- 실행 시점에 스프레드시트 캐릭터 시트를 새로 읽어 최신 데이터를 반영한다.
- 봇 답글 자체가 **참전 신청 스레드**가 된다.
- 이 게시물에 답글을 달면 해당 캐릭터가 참전 신청자 목록에 추가된다.

```
[전투 준비]
```

### `[배치/캐릭터이름/팩션 열]`

전투 시작 전 특정 캐릭터를 수동으로 지정 열에 배치한다.

```
[배치/늑대/적군 3열]
[배치/용병A/아군 2]
```

- 팩션: `아군` 또는 `적군`
- 열: `1`~`7` 또는 `1열`~`7열`

### `[전투 시작]`

참전 신청자 및 수동 배치 목록을 확정하고 전투를 시작한다.

- 아군 참전 신청자는 열(1~7)에 자동 배치(랜덤 분산)된다.
- 첫 페이즈(적군 행동 선언)의 게시물이 퍼블릭으로 게시된다.
- 스프레드시트 `전투 진행` 시트에 저장된다.

### `[페이즈]`

현재 페이즈에서 다음 페이즈로 진행한다.

페이즈 순서:

```
적군 행동 선언 → 아군 행동 → 적군 공격 정산 → 라운드 종료 대기
                                                       ↓
                                         [전투 속행] 으로 다음 라운드 시작
```

| 페이즈       | 설명                | 커맨드 수신 |
|-----------|-------------------|--------|
| 적군 행동 선언  | 적군 캐릭터가 커맨드를 입력한다 | ✅      |
| 아군 행동     | 아군 캐릭터가 커맨드를 입력한다 | ✅      |
| 적군 공격 정산  | 적군의 선언된 행동이 처리된다  | ❌      |
| 라운드 종료 대기 | 버프 갱신 후 대기        | ❌      |

### `[전투 속행]`

라운드 종료 대기 상태에서 다음 라운드(적군 행동 선언)로 진행한다.

### `[현황]`

현재 전장 상태(캐릭터 HP, 위치 등)를 admin 답글로 출력한다.

### `[전투 종료]`

세션을 종료하고 모든 전투 상태를 초기화한다. 스프레드시트에 종료 마킹된다.

### `캐릭터이름 [커맨드]` (프록시)

특정 캐릭터 대신 커맨드를 실행한다. 마스토돈 계정이 없는 적군 캐릭터 조작에 사용한다.

```
늑대 [이동/3 - 공격/전사]
```

## 캐릭터 명령어 (전투 중)

**적용 조건:** 전투가 진행 중이고, 해당 캐릭터의 페이즈인 경우에만 처리된다.

- 아군: `아군 행동` 페이즈의 게시물에 답글
- 적군: `적군 행동 선언` 페이즈의 게시물에 답글

### 커맨드 형식

```
[액션종류/인자...]
```

여러 액션은 ` - `로 연결한다.

```
[이동/3 - 공격/에너미 - 스킬/강타/에너미]
```

### 이동

```
[이동/열번호]
```

- 열번호: `1`~`7`

### 기본 공격

```
[공격/대상이름]
```

### 스킬 사용

```
[스킬/스킬명]                       # 대상 없는 스킬
[스킬/스킬명/대상1/대상2]            # 캐릭터 이름 지정
[스킬/스킬명/3]                     # 열 지정 (광역)
```

### 아이템 사용

```
[아이템/아이템명]           # 자신에게 사용
[아이템/아이템명/대상이름]  # 대상 지정
```

## 비전투 명령어 (캐릭터)

`char_dict`에 등록된 모든 캐릭터가 사용할 수 있다. 전투 맥락과 무관하게 언제든지 사용 가능하다.

### `[판정/스탯]`

1d6을 굴려 해당 스탯값을 더한 결과를 출력한다.

```
@system [판정/마법]
@system [판정/기술]
```

사용 가능한 스탯: `육체` · `지식` · `인간` · `마법` · `기술`

출력 예시:

```
[마법] 4+3 → 「7」
```

### `[의뢰]` — 일일 의뢰

현재 위치에서 의뢰를 받는다. 1일 1회 제한.

**흐름:**

```
캐릭터: @system [의뢰]
  └→ 봇: 의뢰 내용 설명 (스프레드시트 '일일 의뢰' 시트에서 랜덤 선택)

캐릭터: @봇답글 [판정/스탯] (롤플레이 포함 가능)
  └→ 봇: [스탯] 주사위+값 → 「합계」
        (성공 유형별 메시지)
        의뢰를 완수했다. 사례로 1G를 획득했다.
```

판정 합계에 따라 성공 유형이 결정되고, `일일 의뢰 결과 메시지` 시트에서 해당 유형의 메시지를 랜덤으로 선택한다.

| 합계  | 성공 유형    |
|-----|----------|
| ≥ 7 | 대성공      |
| 5–6 | 성공       |
| ≤ 4 | 아슬아슬한 성공 |

- 결과와 관계없이 항상 **1G 획득**된다.
- 골드와 날짜가 스프레드시트 캐릭터 시트에 자동 업데이트된다.
- 오늘 이미 수행했을 경우: "오늘 이미 의뢰를 수행했습니다."
- 현재 위치에 의뢰가 없을 경우: "현재 위치에서 받을 수 있는 의뢰가 없습니다."

### `[상시조사]` — 상시조사

`현위치` 시트에서 `investigation_active = TRUE`일 때만 사용 가능하다.

**흐름:**

```
캐릭터: @system [상시조사]
  └→ 봇: 장소 선택 메뉴 (3개 수주처 + 자율 탐사)

캐릭터: @봇답글 [장소명] 또는 장소명
  ├→ (의뢰 존재 & 미수주) 봇: 의뢰 개요 + "[수락] 입력" 안내
  ├→ (이미 다른 캐릭터가 수주) 봇: 해당 장소 묘사만 출력
  └→ (자율 탐사 선택) 봇: "자유롭게 돌아다닐 수 있습니다."

캐릭터: @봇답글 [수락]
  └→ 봇: "수락 확인. 「의뢰명」 의뢰를 수주했습니다."
```

**합류 규칙:**

다른 캐릭터가 수주한 의뢰의 개요 게시물에 `[수락]`을 답글로 달면 해당 의뢰에 합류할 수 있다.

**제한:**

- 이번 상시조사 구간에서 1인 1의뢰만 수주 가능하다.
- 이미 수주했을 경우: "이번 구간에서 이미 의뢰를 수주했습니다."

## 디스패치 흐름

봇이 멘션을 받으면 아래 순서로 처리 경로를 결정한다.

```
멘션 수신
│
├─ 1. 발신자가 Admin 계정?
│      └→ Admin 커맨드 처리 (전투 관리)
│
├─ 2. [전투 준비] 게시물에 대한 답글?
│      └→ 참전 신청 목록에 추가
│
├─ 3. 현재 페이즈 게시물에 대한 답글? (전투 중)
│      └→ 캐릭터 커맨드 처리 (이동/공격/스킬/아이템)
│
├─ 4. 봇의 [의뢰] 안내 게시물에 대한 답글? + [판정/스탯] 포함?
│      └→ 일일 의뢰 판정 처리
│
├─ 5. 봇의 [상시조사] 메뉴 게시물에 대한 답글?
│      └→ 장소 선택 처리 → 의뢰 개요 또는 탐사 안내 반환
│
├─ 6. 봇의 의뢰 개요 게시물에 대한 답글? + [수락] 포함?
│      └→ 의뢰 수락 처리
│
├─ 7. [판정/스탯] 포함?
│      └→ 독립 판정 처리 (롤플레이용)
│
├─ 8. [의뢰] 포함?
│      └→ 일일 의뢰 시작
│
└─ 9. [상시조사] 포함?
       └→ 상시조사 메뉴 제공 (현위치 시트에서 실시간 조회)
```

> **우선순위 원칙:** 답글 맥락(어느 게시물에 달렸는지) 판단이 독립 키워드 판단보다 항상 먼저다.
> 즉, 일일 의뢰 판정 게시물에 `[판정/마법]`을 달면 독립 판정이 아닌 일일 의뢰 판정으로 처리된다.
